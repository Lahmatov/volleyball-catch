# Dino Egg Catch для Roblox

Один скрипт сам строит всё поле: 10 кругов, в каждом сидит динозавр
(золотой, радужный, зелёный или красный), а вокруг лежат 5 яиц.

## Как запустить в Roblox Studio

1. Открой Roblox Studio и создай новое место: **New → Baseplate**.
2. В окне **Explorer** найди **ServerScriptService**, нажми на нём **+** и выбери **Script**.
3. Удали текст `print("Hello world!")` и вставь туда всё из файла
   [`src/DinoEggCatch.server.lua`](src/DinoEggCatch.server.lua).
4. Нажми **Play**. Через 10 секунд начнётся тайм.
5. Чтобы в игру заходили только 5 человек: **Home → Game Settings → Places → Max Players = 5**.
   Если зайдёт шестой, скрипт его всё равно вежливо выкинет.
6. Чтобы поиграть с друзьями: **File → Publish to Roblox**.

Проверить вдвоём или впятером можно прямо в Studio:
**Test → Clients and Servers → 2 Players → Start**.

## Правила

- Забеги в круг, схвати яйцо и убеги за белые точки. Яйцо засчитывается людям.
- Если динозавр поймает человека, динозаврам дают 1 поинт.
- В круге может быть только один человек. Если второй лезет, круг ломается и выталкивает его.
- Один тайм идёт 2 минуты. Кто наберёт больше, получает кубок 🏆

## Что можно поменять

В начале скрипта есть таблица `CONFIG`: длина тайма, размер кругов,
скорость людей. Скорость каждого динозавра задаётся в `DINO_TYPES`.

Для тех, кто пользуется Rojo, есть `default.project.json`.
