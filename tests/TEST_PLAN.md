Запуск всех тестов: `npm test` (нужны `npm install` и [Lune](https://github.com/lune-org/lune)).
Отдельно: `npm run test:unit` (юнит), `npm run test:e2e` (E2E: браузер + сервер Roblox + экран) и `npm run test:roblox-cloud` (в настоящем Roblox, нужен ключ).
